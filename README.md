# Dave Oh My Posh

A clean, modern Oh My Posh theme built around the Tokyo Night color palette.

## Features

- 🎨 Tokyo Night colors
- 💊 Rounded pill segments
- 🌿 Git integration
- 🐧 Automatic Linux distro icons
- 💻 Bash support
- 🔤 Nerd Font compatible

## Installation

```bash
./install.sh
```

## Requirements

- Oh My Posh
- Nerd Font
- Bash
